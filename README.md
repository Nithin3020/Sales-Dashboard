# Sales-Dashboard (Interactive Dashboard using MS Excel)
## Project Objective
The dashboard provides a comprehensive view of sales performance, enabling users to quickly identify trends, patterns, and insights across different dimensions such as time, region, product category, and customer segments. 

## Dataset used
- <a href="https://github.com/Nithin3020/Sales-Dashboard/blob/main/Sample_data.xlsx">Dataset</a>

## Questions
- What is the overall sales performance over time? 
-	Which regions generate the highest revenue? 
-	Which product categories and sub-categories perform best? 
-	Who are the top customers contributing to revenue? 
-	What is the relationship between sales and profit? 
-	Which time periods show peak sales activity? 
-	Are there any underperforming regions or products? 
-	How does customer segmentation impact sales?
  
## Dashboard Interaction
- <a href="https://github.com/Nithin3020/Sales-Dashboard/blob/main/SALESDASHBOARD.pbix">View Dashboard</a>

## Key Features 
-	Revenue Analysis – Track total sales, profit, and growth trends  
-	Time-Based Insights – Monthly and yearly performance breakdown  
-	Regional Performance – Compare sales across different locations  
-	Product Analysis – Identify top-performing and low-performing products  
-	Customer Insights – Understand purchasing behavior and segmentation  
-	Interactive Filters – Dynamic slicers for customized data exploration
